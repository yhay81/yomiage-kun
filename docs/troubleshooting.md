# トラブルシューティング

## Bot がオンラインにならない

- アプリの Bot トークンをもう一度 **検証して保存**します。
- Discord Developer Portal の Bot ページでトークンを Reset した場合、古い保存値は使えません。
- OS の日時が大きくずれていないか、Discord への通信がファイアウォールで遮断されていないか確認します。
- アプリ画面のエラー文を確認します。トークンを Issue へ貼らないでください。

## 投稿を読み上げない

- Developer Portal で **Message Content Intent** を有効にします。
- 投稿したテキストチャンネルで `/join` を実行したか確認します。
- `/status` で対象チャンネルを確認します。
- Bot に対象チャンネルの View Channel 権限があるか確認します。
- Bot の起動後に Intent を変更した場合は、いったん停止して再起動します。

## `/join` が表示されない

- Bot を一度サーバーから削除し、アプリの **サーバーへ追加**から再招待します。
- 招待 URL に `applications.commands` スコープが必要です。
- Discord クライアントを再起動し、コマンド登録が反映されるまで数分待ちます。

## ボイスチャンネルへ入れない

- `/join` を実行する本人が先にボイスチャンネルへ入ります。
- Bot に View Channel、Connect、Speak 権限があるか確認します。
- Stage Channel ではなく通常の Voice Channel で試します。

## 音が出ない

- AivisSpeech / VOICEVOX を先に起動します。
- アプリの **接続テスト**を実行します。
- 標準エンドポイントは AivisSpeech が `http://127.0.0.1:10101`、VOICEVOX が `http://127.0.0.1:50021` です。
- 選択した話者 ID が音声エンジンに存在するか確認します。
- Discord で Bot のユーザー音量が 0 になっていないか確認します。

## 音声エンジンが見つからない

「AivisSpeechが見つかりません」または「VOICEVOXが見つかりません」と表示された場合は、読み上げくんの故障ではなく、音声合成ソフトが応答していない状態です。

1. 選択中のAivisSpeechまたはVOICEVOXを起動します。
2. エンジンの画面が使用可能になるまで待ちます。
3. 読み上げくんの**接続を確認**をもう一度押します。
4. 解決しない場合は、エンドポイントを既定値へ戻します。
   - AivisSpeech: `http://127.0.0.1:10101`
   - VOICEVOX: `http://127.0.0.1:50021`

VPN、プロキシ、セキュリティソフトを使用している場合は、localhostへの接続を遮断していないか確認してください。

## 読み上げが遅れる・一部が読まれない

サーバーごとのキューは既定で 32 件です。大量投稿時に上限を超えた新規投稿は、遅延とメモリ増加を防ぐため読み上げません。

- より高速な音声モデルまたは GPU 対応エンジンを使います。
- 読み上げ専用チャンネルを作ります。
- `/skip` で長い発話を飛ばします。
- 同じ PC で同時に接続するサーバー数を減らします。

## macOS で開けない

署名・公証済みの公式 Release を使ってください。開発ビルドでは、システム設定の「プライバシーとセキュリティ」に確認が表示されることがあります。出所不明のバイナリに対して Gatekeeper を恒久的に無効化しないでください。

## Windows で WebView2 を求められる

インストーラーは WebView2 bootstrapper を含む構成です。企業ネットワークでダウンロードが遮断される場合は、管理者へ Microsoft Edge WebView2 Runtime の配布を依頼してください。
