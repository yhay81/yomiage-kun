# ADR-0001: 利用者ホストのデスクトップアプリ

- Status: Accepted
- Date: 2026-07-26

## Context

共有 Discord Bot は初回導入が簡単ですが、常時稼働のコンピュート、音声合成、転送量、監視、秘密管理が利用者数に比例します。個人 OSS の運営者が無料で最高品質の音声を無制限提供することは持続可能ではありません。

従来のローカル Python Bot は運営コストを避けられる一方、runtime、依存パッケージ、設定ファイル、Bot token の扱いが利用者にとって難しいものでした。

## Decision

Windows と macOS のデスクトップアプリを配布し、各利用者が自分の Bot Application とローカル TTS を使います。アプリは Developer Portal への導線、token 検証、最小権限の招待 URL、OS 資格情報ストア、自動起動、稼働状態を一体化します。

共有 Bot、開発者運営 API、アカウントシステム、課金システムは設けません。

## Consequences

### Positive

- 運営者の変動費はほぼ 0
- 利用者ごとに障害と負荷が分離される
- token と投稿本文の第三者預託がない
- ローカル GPU と高品質モデルを直接利用できる
- OSS fork とカスタマイズが容易

### Negative

- 利用者が Discord Application を初回作成する必要がある
- PC と音声エンジンを起動している間だけオンラインになる
- インストーラー署名と macOS notarization が必要
- モバイル端末だけではホストできない

初回導入の難しさは、アプリ内の段階的ウィザード、token の即時検証、自動生成した招待 URL、詳細なドキュメントで軽減します。
