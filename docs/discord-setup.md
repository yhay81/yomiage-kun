# Discordの「読み上げ役」を準備する

読み上げくんがDiscordの通話へ入り、声を流すための専用の役を作ります。

- 作るのは最初の一度だけです。
- 別の人のDiscordアカウントは必要ありません。
- 開発者への申し込みや月額料金はありません。
- 読み上げ中は、あなたのパソコンで読み上げくんを動かします。

Discordのページには英語のボタンがあります。このページでは、画面に表示される名前を太字でそのまま書いています。

## 始める前に

読み上げたいDiscordサーバーへアプリを追加できる権限が必要です。自分で作ったサーバーなら、そのまま進められます。

## 1. 読み上げ役を作る

1. 読み上げくんの **設定** を開きます。
2. **Discordの開発者ページを開く** を押します。
3. Discordへログインする画面が出たら、いつものアカウントでログインします。
4. 右上の **New Application** を押します。
5. 名前に「読み上げくん」と入力します。
6. 利用条件への確認を入れ、**Create** を押します。

作成後に設定画面が開けば、ここまで完了です。

## 2. メッセージを読む許可を出す

1. 左側の一覧から **Bot** を開きます。
2. **Privileged Gateway Intents** という見出しまで下へ進みます。
3. **Message Content Intent** をオンにします。
4. 画面下に **Save Changes** が表示されたら押します。

**Message Content Intent** は、読み上げ役が投稿された文章を受け取るための許可です。ほかの2つの項目はオンにしなくて大丈夫です。

新しく作った場合、読み上げ役は最初から用意されています。古い画面で **Add Bot** が表示されたときだけ、そのボタンを押してください。

## 3. 専用の合言葉を保存する

1. 同じ **Bot** ページの上の方にある **Reset Token** を押します。
2. Discordの確認画面が出たら、案内に沿って本人確認をします。
3. 表示された長い文字列を **Copy** でコピーします。
4. 読み上げくんへ戻ります。
5. **ボットのトークン** 欄へ貼り付け、**確認して保存** を押します。

「ボットのトークンを安全に保存しました」と表示されたら完了です。

> [!IMPORTANT]
> **コピーした文字列は、読み上げ役専用のパスワードです。** スクリーンショット、チャット、問い合わせ、GitHubへ貼らないでください。読み上げくんはWindowsまたはMacの安全な保管場所へ保存します。

コピーした文字列をもう一度表示することはできません。なくした場合は **Reset Token** で新しく作り直し、読み上げくんへ保存し直せば大丈夫です。

## 4. 使うサーバーへ追加する

1. 読み上げくんの **サーバーに追加** を押します。
2. 読み上げたいDiscordサーバーを選びます。
3. 表示された内容を確認し、**認証** を押します。

Discordのメンバー一覧に「読み上げくん」が現れたら、追加できています。この時点でオフラインと表示されていても問題ありません。

読み上げくんが求めるのは、チャンネルを見る、メッセージを送る、通話へ接続する、話すための権限だけです。サーバー全体を管理する権限は求めません。

## 5. 読み上げを試す

1. AivisSpeechまたはVOICEVOXを起動します。
2. 読み上げくんの設定で **接続を確認** を押します。
3. 「音声エンジンに接続できました」と表示されたことを確認します。
4. 読み上げくんの **読み上げを始める** を押します。
5. Discordのメンバー一覧で、読み上げ役がオンラインになったことを確認します。
6. 自分が通話へ入り、読み上げたいテキストチャンネルで `/join` と入力します。
7. 短い文章を送って、声が聞こえることを確認します。

読み上げを終えるときは `/leave`、今の読み上げを飛ばすときは `/skip` と入力します。

安全のため、`/join`と`/leave`は「サーバーの管理」権限を持つ人だけが実行できます。`/skip`は読み上げくんと同じ通話に参加している人だけが使えます。

## `/join` が表示されないとき

次の順に確認してください。

1. 読み上げ役を一度Discordサーバーから外します。
2. 読み上げくんの **サーバーに追加** から、もう一度追加します。
3. 数分待ち、Discordをいったん終了して開き直します。

## 読み上げ役がオンラインにならないとき

- 読み上げくんに「読み上げ中」と表示されているか確認します。
- **確認して保存** をもう一度押します。
- Discordの **Bot** ページで **Reset Token** を押した場合は、新しい文字列を読み上げくんへ保存し直します。
- **Message Content Intent** がオンになっているか確認します。

さらに確認したい場合は、[うまく動かないときの確認](troubleshooting.md)をご覧ください。

## 家族やチームで使うとき

動かすパソコンを一台決めてください。読み上げ中は、そのパソコンと声のアプリを起動しておく必要があります。

同じ読み上げ役を、自分が管理する複数のDiscordサーバーへ追加することもできます。専用の合言葉をほかの人へ渡す必要はありません。
