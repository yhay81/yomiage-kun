# はじめに

読み上げくんは、利用者自身のパソコンで動作するDiscord読み上げアプリです。共有サービスへの登録や有料プランはありません。

## 初回だけ必要なもの

- Windows 11 または macOS 13 以降
- Discordアカウントと、ボットを追加できるサーバー
- AivisSpeechまたはVOICEVOX
- Discordの開発者ページで作成する自分専用ボット

ボットの作成には通常5〜10分かかります。一度作成すれば、同じDiscordユーザーが管理する複数サーバーへ同じボットを追加できます。ただし、ボットのトークンを他人へ渡したり、複数人で共有したりしないでください。

## インストール

1. [リリース一覧](https://github.com/yhay81/yomiage-kun/releases)を開きます。
2. Windowsは`.exe`、macOSはお使いのMacに合う`.dmg`を1つ取得します。
3. 日本語で表示されるインストーラを開き、画面の案内に従います。
4. AivisSpeechまたはVOICEVOXを起動してから読み上げくんを開きます。

署名済みリリースがまだ公開されていない開発版は、ソースからビルドしてください。

## 初回設定

普段使う画面には、現在の状態と**読み上げを始める**ボタンだけを表示します。

初回だけ**設定を開く**を押して、次の2項目を設定します。

1. **Discordとつなぐ**: トークンを確認して保存し、ボットをサーバーへ追加します。
2. **読み上げる声を選ぶ**: **自動で見つける**を押し、声を名前から選びます。**この声を試す**で確認して保存します。

Discord側の詳しい手順は[Discordボットの設定](discord-setup.md)を参照してください。

## 日常の使い方

1. 音声エンジンを起動します。
2. 読み上げくんを起動し、**読み上げを始める**を押します。
3. Discord でボイスチャンネルへ参加します。
4. 読み上げたいテキストチャンネルで `/join` を実行します。
5. 終了時は `/leave` を実行します。

`/join` を実行したテキストチャンネルだけが読み上げ対象です。ほかのチャンネル、DM、別サーバーの投稿は読み上げません。

ウィンドウを閉じてもボットはタスクトレイ（Windows）またはメニューバー（macOS）で動き続けます。完全に終了するにはアイコンのメニューから**終了**を選びます。自動起動を有効にすると、次回ログイン時にアプリとボットが起動します。

## Discord コマンド

| コマンド | 動作 |
|---|---|
| `/join` | 実行者のボイスチャンネルへ参加し、現在のテキストチャンネルを読み上げる |
| `/leave` | 読み上げを終了し、ボイスチャンネルから退出する |
| `/skip` | 再生中の発話をスキップする |
| `/status` | 対象チャンネルと合成待ち件数を表示する |

困ったときは [トラブルシューティング](troubleshooting.md) を確認してください。

詳しい対応OSは[対応環境](compatibility.md)で確認できます。アプリ画面下の**診断情報を保存**を使うと、トークンや読み上げ内容を含まない確認用ファイルを作れます。
