# はじめに

Yomiage-kun は、利用者自身の PC で動作する Discord 読み上げ Bot です。共有サービスへの登録や有料プランはありません。

## 初回だけ必要なもの

- Windows 11 または macOS 13 以降
- Discord アカウントと、Bot を追加できるサーバー
- AivisSpeech または VOICEVOX
- Discord Developer Portal で作成する自分専用 Bot

Bot の作成には通常 5〜10 分かかります。一度作成すれば、同じ Discord ユーザーが管理する複数サーバーへ同じ Bot を追加できます。ただし、Bot トークンを他人へ渡したり、複数人で共有したりしないでください。

## インストール

1. [Releases](https://github.com/yhay81/yomiage-kun/releases) を開きます。
2. Windows は `.msi` または `.exe`、macOS はアーキテクチャに合う `.dmg` を取得します。
3. インストーラーを開き、OS の案内に従います。
4. AivisSpeech または VOICEVOX を起動してから Yomiage-kun を開きます。

署名済みリリースがまだ公開されていない開発版は、ソースからビルドしてください。

## 初回セットアップ

アプリには 3 つのカードがあります。

1. **Discord Bot**: トークンを検証・保存し、Bot をサーバーへ追加します。
2. **音声エンジン**: エンジン、話者、速度、抑揚、音量を選び、接続をテストします。
3. **読み上げを開始**: Bot をオンラインにし、稼働状態を確認します。

Discord 側の詳しい手順は [Discord Bot セットアップ](discord-setup.md) を参照してください。

## 日常の使い方

1. 音声エンジンを起動します。
2. Yomiage-kun を起動し、**Bot を開始**を押します。
3. Discord でボイスチャンネルへ参加します。
4. 読み上げたいテキストチャンネルで `/join` を実行します。
5. 終了時は `/leave` を実行します。

`/join` を実行したテキストチャンネルだけが読み上げ対象です。ほかのチャンネル、DM、別サーバーの投稿は読み上げません。

ウィンドウを閉じても Bot はタスクトレイ（Windows）またはメニューバー（macOS）で動き続けます。完全に終了するにはアイコンのメニューから **終了**を選びます。自動起動を有効にすると、次回ログイン時にアプリと Bot が起動します。

## Discord コマンド

| コマンド | 動作 |
|---|---|
| `/join` | 実行者のボイスチャンネルへ参加し、現在のテキストチャンネルを読み上げる |
| `/leave` | 読み上げを終了し、ボイスチャンネルから退出する |
| `/skip` | 再生中の発話をスキップする |
| `/status` | 対象チャンネルと合成待ち件数を表示する |

困ったときは [トラブルシューティング](troubleshooting.md) を確認してください。
