# 読み上げくん

Discordに届いたメッセージを、やさしい日本語の声で読み上げるアプリです。

WindowsとMacで使えます。月額料金や広告はありません。

[公式サイト](https://yomiage.yusuke-hayashi.com/) ・ [ダウンロード](https://github.com/yhay81/yomiage-kun/releases) ・ [困ったとき](docs/troubleshooting.md)

[![読み上げくん](https://yomiage.yusuke-hayashi.com/og.jpg)](https://yomiage.yusuke-hayashi.com/)

## こんなときに便利です

- ゲーム中に、手を止めずにメッセージを聞きたい
- 作業中に、仲間からのメッセージを聞き逃したくない
- 自分の好きな声や話す速さで読み上げてほしい
- みんなで使うための月額サービスを契約したくない

読み上げくんは、あなたのパソコンで動きます。開発者が用意した有料の中継サービスは使いません。

## はじめる前に

最初に、次の2つだけ準備します。

1. 文章を声にするアプリ
2. Discordの通話へ参加する、自分専用の「読み上げ役」

声のアプリは **AivisSpeechかVOICEVOXのどちらか一つ** で大丈夫です。Discordの準備も最初の一度だけです。

## 1. 声のアプリを準備する

読み上げくんは、声そのものを作るためにAivisSpeechまたはVOICEVOXを使います。読み上げている間は、選んだアプリも起動しておいてください。

### どちらを選べばよいですか？

- **[AivisSpeech](https://aivis-project.com/AivisSpeech)** — 感情のある自然な声を使いたい方に向いています。迷ったときはこちらから始められます。
- **[VOICEVOX](https://voicevox.hiroshiba.jp/)** — いろいろなキャラクターの声から選びたい方に向いています。

どちらも無料でダウンロードできます。声ごとの利用条件は、それぞれの公式ページで確認してください。

### つなぎ方

1. 上の公式ページから、使いたい声のアプリを入れます。
2. 声のアプリを起動し、最初の画面が表示されるまで待ちます。
3. 読み上げくんを開き、右上の **設定** を押します。
4. **自動で見つける** を押します。
5. 表示された声を名前から選び、**この声を試す** で確認します。
6. **この設定を保存** を押します。

「接続済み」と表示されたら準備完了です。AivisSpeechとVOICEVOXの両方が起動している場合も、使いたい方を選べます。

接続できないときは、次の順に確認します。

- 声のアプリが起動している
- 声のアプリが「準備中」ではなく、使える画面になっている
- **自動で見つける** をもう一度押す
- 一度閉じて、声のアプリを先に起動してから読み上げくんを開き直す

## 2. Discordの「読み上げ役」を準備する

### なぜ読み上げ役が必要ですか？

Discordの通話で音を流すには、通話へ参加する専用の役が必要です。読み上げくんでは、あなたが管理する小さな専用アカウントを一つ作ります。

別の人のDiscordアカウントは必要ありません。開発者へ申し込む必要もなく、利用料金もかかりません。

### 作り方

1. 読み上げくんの **設定** を開き、**Discordの開発者ページを開く** を押します。
2. Discordのページで **New Application** を押します。
3. 名前に「読み上げくん」と入力し、利用条件への確認を入れて **Create** を押します。
4. 左側の **Bot** を開きます。下へ進み、**Message Content Intent** をオンにして **Save Changes** を押します。これは、読み上げ役がメッセージ本文を受け取るための許可です。
5. 同じ **Bot** のページで **Reset Token** を押し、表示された文字列を **Copy** でコピーします。
6. 読み上げくんへ戻り、**ボットのトークン** 欄へ貼り付けて **確認して保存** を押します。
7. **サーバーに追加** を押し、使いたいDiscordサーバーを選んで許可します。

「ボットのトークンを安全に保存しました」と表示され、Discordのメンバー一覧に読み上げ役が現れたら準備完了です。

> [!IMPORTANT]
> **ボットのトークンは、読み上げ役専用のパスワードです。** スクリーンショット、チャット、問い合わせ、GitHubへ貼らないでください。読み上げくんはWindowsまたはMacの安全な保管場所に保存します。

ボタンの位置も含めた手順は、[Discordの準備をくわしく見る](docs/discord-setup.md)で確認できます。

## 読み上げを始める

初回の準備が終わったら、ふだんは3手順です。

1. AivisSpeechまたはVOICEVOXを起動します。
2. 読み上げくんで **読み上げを始める** を押します。
3. Discordの通話に入り、メッセージ欄へ `/join` と入力します。

読み上げを終えるときは `/leave`、今の読み上げを飛ばすときは `/skip` と入力します。

## うまくいったか確認する

- 読み上げくんに「読み上げ中」と表示されている
- Discordのメンバー一覧で、読み上げ役がオンラインになっている
- `/join` のあと、読み上げ役が自分と同じ通話へ入っている
- テキストチャンネルへ短い文章を送ると、声が聞こえる

うまくいかないときは、[困ったときの確認](docs/troubleshooting.md)をご覧ください。

問い合わせや不具合報告では、画面下の **診断情報を保存** が役立ちます。このファイルにボットのトークンや読み上げた文章は含まれません。

## 安心して使うために

- メッセージから声を作る処理は、あなたのパソコンの中で行います。
- 読み上げた声を、パソコンへ音声ファイルとして残しません。
- Discordから発行された合言葉は、WindowsまたはMacの安全な保管場所に保存します。
- 開発者がメッセージや合言葉を受け取ることはありません。

家族やチームで使う場合は、動かすパソコンを一台決めてください。読み上げ中は、そのパソコンと声のアプリを起動しておく必要があります。合言葉をほかの人へ渡す必要はありません。
